PRODUCTS / DEVELOPMENT ROADMAP

Build the pathfinder.
Learn from the mission.

Our program connects spacecraft inference software with a compact hosted payload, then uses flight evidence to guide dedicated solar compute nodes.

What we are developingProgram milestonesLong-term targets

01 / THE PRODUCT FAMILY

Software and hardware.
One staged program.

SI RUNTIME

Inference within mission limits.

Software intended to run approved AI workloads on compatible spacecraft accelerators. The host operator retains command authority. Reliability and hardware portability are targets for validation.

SI-P1 PATHFINDER

A hosted compute payload.

Jetson T5000, from the NVIDIA Thor family, is the reference platform. Jetson AGX Orin Industrial is the fallback; a Lite configuration remains an option if it better fits the host and workload.

SI NODE

Dedicated solar compute.

A planned 10–20 kW compute spacecraft on a purchased high-power bus. The node concept uses a dawn–dusk orbit and requires its own development and financing.

CLUSTERS

Capacity built from nodes.

A longer-term program to aggregate orbital compute. Architecture and deployment depend on demonstrated economics, available launches and contracted demand.

These are development plans. Hardware selection and qualification follow the workload, host interface and measured power, thermal and radiation performance. No manufacturer or host is represented as a partner.

02 / TWO EARLY ORBITAL STEPS

Orbit-0.
Software on an existing host.

The first objective is an approved software experiment using a GPU already in orbit. It targets earlier orbital learning while the dedicated pathfinder is developed.

Access, workload compatibility and operator approval must be agreed with a provider. Orbit-0 is a program target, not a reserved service.

SI-P1.
Our hosted pathfinder.

The hardware program targets a flight-ready unit with environmental test evidence and a defined host interface. The host provides the spacecraft services required to operate it.

The SI-P1 launch target is H1 2028, dependent on the host manifest, qualification and flight financing.

03 / THE FIRST PROGRAM

A 13-month plan.
Defined gates.

The plan covers software development, Orbit-0, SI-P1 build and tests, and a host reservation. The SI-P1 launch also needs a host slot and separate flight funding.

04 / LONGER-TERM CAPACITY TARGETS

Follow the evidence.
Expand the useful capacity.

  1. 2029–30

    Node-1

    A dedicated solar compute demonstrator, following pathfinder evidence and a separately financed development program.

  2. 2031–32

    First MW-class cluster

    Aggregate useful capacity only when launch access, infrastructure costs and customer needs support it.

  3. BY 2035

    100 MW-class ambition

    A conditional scale objective requiring substantial new capital, fleet deployment and customer commitments.

  4. ECONOMIC GATE

    Three costs must improve together

    Launch cost to the operating orbit, spacecraft cost per watt and mass per kilowatt define the scale economics.

Future nodes are modeled in a dawn–dusk sun-synchronous orbit with approximately 96% annual sunlight. Seasonal eclipses remain, and the chosen orbit requires mission-specific validation. The first pathfinder follows its selected host.

The program is launch-agnostic. A 20 kW node is planned at under a tonne, within rideshare and medium-lift capacity. Cluster economics improve sharply with heavy-lift prices, and only the largest clusters need heavy-lift vehicles. No launch provider is represented as a partner.
